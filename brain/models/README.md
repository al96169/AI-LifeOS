# models

模型接入与提示装配。

## 职责

- 按 `../../DNA/架构与目录.md` 的加载顺序，把实例的 `assistant.md`、`rules/`、命中的 `skills/`、`short-term/context.md`、`long-term/capabilities.md` 与 `../../DNA/决策循环.md` 拼成提示
- 调用兼容接口，需支持工具调用（Function Calling），否则无法驱动 `../../tools/` 的动作函数
- 端点、模型名、温度、超时与重试取自实例的 `config.md`
- 把返回的工具调用交给 `../runtime/` 转 `../../tools/` 执行

## 换模型

只改这一处。换供应商、换型号、按场景分流，都不动定义文件，也不动工具层。

## 上下文预算

按需加载：不把整个实例塞进每次请求，只放命中的场景与必要规则。长期记忆只取相似度最高的少量条目作少样本。感知结果本地缓存，避免为同一事实重复请求。
