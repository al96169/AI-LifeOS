# brain（运行时引擎）

引擎把定义读进来、按 `DNA/决策循环.md` 推进决策，把动作交给工具层。不含任何判断，不含用户信息。

| 目录 | 职责 | 不做什么 |
|---|---|---|
| `runtime/` | 主循环、会话装配、状态读写、开机自启 | 不含业务判断 |
| `models/` | 模型接入与提示装配 | 不解析业务语义 |
| `triggers/` | 定时与事件触发 | 不决定要不要打扰 |
| `router/` | 登记各宿主反调方式，唤醒其一 | 不判断该不该打扰 |

装配一次决策：找实例 → 读 DNA 规范与 `决策循环.md` → 读实例 `assistant.md`/`rules/`/命中的 `skills/`/`context.md`/`capabilities.md` → 拼成提示给 `models/` → 拿到工具调用转 `tools/` 执行 → 结果按 `记忆规范.md` 写回。

边界：可随时被重写换语言。自检代碼有无出现场景名、阈值或「选 A 选 B」取舍，有即错，条文见 `DNA/铁律.md`。
