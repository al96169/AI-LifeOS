# triggers

触发器回答一个问题：现在该不该请推理段看一次。规格见 `../../DNA/触发器.md`，这里说怎么实现。

## 三种输入，一个循环

| 源 | 实现要点 |
|---|---|
| 定时 | 读实例 `config.md` 调度时刻表，到点触发，不受宿主定时器粒度限制 |
| 变化 | 订阅感知量，记住上次取值，本次跨过阈值时触发 |
| 外部 | 监听外部事件：回调、消息、文件落地 |

## 规则来自数据

触发条件不在代码里：装实例时读场景「触发」段与 `config.md` 的调度表、阈值、感知订阅。改数据即改触发。

## 产出

唯一产出是把一条待办写进 `short-term/queue/pending/`，格式见 `触发器.md`。写完唤醒推理段（方式由宿主描述决定，触发器不认识具体软件）。

## 要做与不要做

要做：时机判断、去重、写队列、唤醒、回收超时领取。不要做：判断该不该打扰、决定怎么做、执行任何对外动作。

## 去重与离线

同场景同情境指纹只写一条；已有未消费同类待办则追加「再次满足」时间；指纹取影响判断的量不取时间戳。推理段不可用时待办留队列不丢，按剩余价值决定补做/保留/过期；不可错过的动作按保留的最近有效结论执行并标降级，再不行退画像固定经验值。
