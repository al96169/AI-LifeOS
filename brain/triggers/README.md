# triggers

触发信号的生产者。

## 触发类型

| 类型 | 说明 |
|---|---|
| 定时 | 按实例 `config.md` 的调度时刻表产生信号 |
| 事件 | 感知量发生显著变化时产生信号，例如降雨概率跨过阈值 |
| 外部回调 | 用户在 IM 里发来消息、点了撤销按钮 |

## 边界

引擎只提供触发类型与机制，具体时刻一律来自实例的 `config.md`，不在代码里写死任何时间点。新增一个调度时刻属于改数据，不属于改代码。

## 去重

情境与上次一致且状态未变化时不重复触发，避免重复打扰。判断规则见 `../../DNA/决策循环.md` 的「何时不该触发」。
