# runtime

常驻服务的入口、主循环与守护进程。规格见 `../../DNA/守护进程.md` 与 `../../DNA/决策循环.md`。

## 职责

- **单实例守门**：启动取机器锁，再逐个为 user_id 取人格锁，两级锁不能省
- **常驻自愈**：随开机自启，主循环打点，卡死由内部看门狗触发退出、外部服务管理器拉起
- **会话装配**：按 user_id 装载实例，一进程可同时持多用户会话，状态不交叉
- **推进决策**：按 triggers 触发信号启动一次决策，按 `决策循环.md` 走
- **记忆读写**：按 `记忆规范.md` 读写实例长期/短期记忆
- **只读校验**：以只读方式加载 DNA，算目录指纹与 state/ 里上次比对，不一致向用户报告

## 处理一条待办

```
触发器写待办 → 移到 claimed/（记领取者与时刻）→ models/ 拼上下文与工具清单
 → chat(messages, tools) → 有 tool_calls 交 tools/ 执行，结果回灌再调
 → 收敛 → 收尾（对外动作由 tools/ 执行）→ 结论写 done/，更新 context.md
```

两条硬要求：**幂等**——同待办重复处理不重复执行对外动作，执行器按待办 id 记录，重复调用返回上次结果；**可中断**——进程任一被杀后重启，待办要么还在 claimed 待回收、要么已在 done，无中间态，状态只落文件不驻内存。

## 不做什么

不决定要不要打扰（归 `rules/打扰分级.md`）；不解析业务语义；不修改 DNA。

## 关键行为

| 场景 | 行为 |
|---|---|
| 已有守护进程在跑 | 报告持有者后退出，不抢占 |
| 锁持有者已死 | 判残留，清理后重试一次 |
| 某个人格被其它进程占 | 跳过并记录，其他人格照常 |
| 续租失败 | 进退让态，停对外动作后退出 |
| 强杀/断电 | 锁由 OS 释放；重启后若上次未正常停止，经 IM 报告一次 |
| 连续重启超阈值 | 停重启并告知，不陷入崩溃循环 |

## 命令

| 参数 | 含义 |
|---|---|
| `--user <user_id>` | 只服务指定人格，可重复 |
| `--all` | 服务全部实例 |
| `--status` | 打印各 user_id 持有者、启动时间、心跳 |
| `--takeover` | 显式夺取指定人格锁，需确认 |

## 状态

`state/` 存进程级状态（DNA 指纹、上次运行标记），不入库。锁不在这里，在仓库外机器级目录。
