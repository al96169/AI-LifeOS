# router

路由层是触发器与推理段之间唯一的接线点。

## 它解决什么

触发器不该知道推理段是谁。它把待办交给路由层，由路由层决定叫谁。

```
触发器 → 路由层 → 反调命令 → Agent 软件 → 读人格 → 处理待办 → 写回队列
```

本层本身不含判断：谁来、怎么叫、怎么判在线，都写在登记里；该不该打扰用户、该怎么做，都不归它管。

## 登记

初始化时由 Agent 软件自己写一份登记在本目录下，文件名取它自己的名字。字段与格式见 `../../DNA/初始化引导.md` 的「路由登记」。

可以登记多个。路由层按在线判定筛出可用的，按登记顺序取第一个；都不在线就按 `../../DNA/触发器.md` 的离线规则处理，待办留在队列里不丢。

唤醒时只传一个待办 id。结论由宿主自己写回队列文件，不经过标准输出。

## 边界

只放登记，不放实现。本目录里唯一属于项目的是这份说明；其余文件都是初始化时写下的本机产物，不进版本库——预置任何一份，等于把某个软件写进了项目。
