# router

路由层是触发器与推理段之间唯一的接线点——触发器不知道推理段是谁，把待办交给路由层，由它决定叫谁。

```
触发器 → 路由层 → 反调命令 → Agent → 读人格 → 处理待办 → 写回队列
```

本层不含判断：谁来、怎么叫、怎么判在线都写在登记里；该不该打扰、该怎么做不归它管。

## 登记

初始化时由 Agent 软件自写一份登记在本目录，文件名取自己的名字，字段与格式见 `../../DNA/初始化引导.md`。可登记多个，按在线判定取可用者、按登记序取第一个；都不在线按 `触发器.md` 离线规则处理。唤醒只传待办 id，结论由宿主自写回队列，不经 stdout。

## 边界

只放登记，不放实现。本目录唯一属项目的是这份说明；其余文件都是初始化时写下的本机产物，不入库——预置任何一份等于把某软件写进项目。
