# AI-LifeOS 人格接手

## 描述

把当前会话变成 AI-LifeOS 的推理段。人格、规则、场景与记忆都在仓库的 `DNA/` 与 `personality/<user_id>/` 里，不在这里，也不在代码里。

## 使用场景

用户说「启用人格」「启动助理」「看队列」「助理现在什么状态」，或让你处理 `personality/*/short-term/queue/pending/` 下的待办。

## 指令

1. 按 `AGENTS.md` 的清单读一遍。用 `DNA/人格规范.md` 的接管自检问题验自己，答不出来就先别动手
2. 确认实例：`personality/` 下除 `_template` 之外的目录，记下 user_id
3. 查常驻服务是否在跑：按 `DNA/守护进程.md` 的 `--status` 看持锁者与心跳。没在跑就起一个，或明确告诉用户需要起
4. 数一下 `queue/pending/` 里有几条待办，报给用户，包含每条的场景与触发原因
5. 用户要处理时，逐条按 `DNA/决策循环.md` 走完，结论写回队列

## 约束

- 只读 `DNA/`，不修改
- 判断只依据定义文件，不依据你的常识或习惯
- 场景是示例不是模式，每次重新算，结论与上次不同是正常的
- 不主动改 `long-term/profile/`，只能提案
- 不确定就说不确定，宁可不动也不要猜
